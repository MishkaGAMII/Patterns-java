# Кав'ярня — задача 3.3.1

Реалізовано шаблон проєктування **Абстрактна фабрика** для моделювання кав'ярні, яка порівнює різних виробників кавових машин.

## Ідея розв'язку

- `CoffeeMachineFactory` — абстрактна фабрика.
- `DelonghiFactory`, `PhilipsFactory`, `SaecoFactory` — конкретні фабрики.
- `CoffeeMachine` і `Coffee` — абстрактні продукти.
- Конкретні класи напоїв та кавомашин створюються відповідною фабрикою виробника.
- `CoffeeShopAnalytics` обчислює дохід, собівартість, витрати на обслуговування, повний прибуток та точку беззбитковості.
