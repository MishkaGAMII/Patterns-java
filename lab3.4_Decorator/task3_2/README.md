# Декоратор
## Що реалізовано

У проєкті є:

- `Beverage` — базовий абстрактний клас напою;
- `Espresso`, `DarkRoast`, `Decaf` — конкретні напої;
- `BeverageDecorator` — базовий абстрактний декоратор;
- `Milk`, `Sugar`, `Whip`, `Cream` — декоратори для додавання наповнювачів;
- `Main` — демонстрація роботи програми.

## Створені напої

Відповідно до умови задачі сформовано:

1. Еспресо з двома порціями цукру;
2. Чорну каву з вершками та двома порціями цукру;
3. Чорну каву з кремом та порцією цукру;
4. Каву без кофеїну з молоком та двома порціями цукру.
