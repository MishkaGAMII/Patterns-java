# Лабораторна робота 2. Factory Method
## Завдання 2.3.1 — Кав'ярня

### Умова
Потрібно змоделювати роботу кав'ярні, яка продає напої:
- Espresso
- Americano
- Cappuccino
- Latte

Кожен напій має:
- собівартість;
- ціну продажу.

Необхідно:
- реалізувати шаблон проєктування **Factory Method**;
- обчислити прибуток кав'ярні за певний проміжок часу;
- розширити асортимент іншими напоями.

### Реалізація
У програмі використано шаблон **Factory Method**.

- `Beverage` — абстрактний продукт
- `Espresso`, `Americano`, `Cappuccino`, `Latte`, `Mocha`, `FlatWhite` — конкретні продукти
- `CoffeeShop` — абстрактний творець
- `EspressoShop`, `AmericanoShop`, `CappuccinoShop`, `LatteShop`, `MochaShop`, `FlatWhiteShop` — конкретні творці

### Додані напої
Для розширення асортименту додано:
- `Mocha`
- `FlatWhite`

### Логіка програми
У `Main.java` моделюється продаж напоїв за певний період. Для кожного напою задається кількість продажів. Програма обчислює:
- загальну виручку;
- загальну собівартість;
- загальний прибуток.
