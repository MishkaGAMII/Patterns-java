# Автоконструктор — Flyweight
## Ідея реалізації

- `EngineFactory` кешує двигуни за ключем `power + fuel`.
- `WheelFactory` кешує колеса за ключем `material + diameter`.
- `CarBuilder` під час встановлення деталей отримує канонічні екземпляри з фабрик,
  тому автомобілі з однаковими характеристиками використовують спільні об'єкти деталей.

Під час роботи симулятор створює автомобілі та виводить кількість унікальних
об'єктів `Engine` і `Wheel`, що дозволяє побачити повторне використання деталей.
