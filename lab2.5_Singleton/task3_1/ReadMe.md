## Що зроблено

- реалізовано шаблон **Прототип** для класу `Equation` та його нащадків;
- збережено ієрархію рівнянь із задачі **2.3.2**:
    - `Equation` — лінійне рівняння;
    - `QuadraticEquation` — квадратне рівняння;
    - `BiQuadraticEquation` — біквадратне рівняння;
- додано парсер вхідних даних з текстових файлів;
- реалізовано групування рівнянь за кількістю розв'язків;
- визначається рівняння з найменшим та найбільшим коренем серед тих, що мають рівно один розв'язок.

## Де використано Прототип

Інтерфейс `ClonableEquation` оголошує метод `copy()`, а кожен клас рівняння повертає власну копію через конструктор копіювання.
У `Main` після зчитування вхідних даних створюються копії всіх рівнянь, і вже вони беруть участь в подальшому аналізі.
