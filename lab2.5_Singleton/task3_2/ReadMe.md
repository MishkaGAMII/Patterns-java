Одинак для Директора
====================

У задачі 4.3.1 застосовано шаблон проєктування **Одинак** для можливості існування лише одного екземпляра класу `Director`.

Що зроблено:
- `Director` має закритий конструктор;
- доступ до єдиного екземпляра здійснюється через `Director.getInstance()`;
- реалізація виконана через `static holder`, тобто з лінивою та потокобезпечною ініціалізацією;
- клас `Director` формує кілька типових конфігурацій автомобілів;
- для складових автомобіля використано окремі будівельники: `EngineBuilder`, `TransmissionBuilder`, `WheelBuilder`, `CarBuilder`.
