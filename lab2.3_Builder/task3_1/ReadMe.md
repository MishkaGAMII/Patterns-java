Автомобільний завод.
=======================

Реалізація завдання 4.3.1 для шаблону проєктування «Будівельник».

У моделі реалізовано:
- клас `Car` з атрибутами тип кузова, клас автомобіля, колір, двигун, трансмісія, диски та гума;
- окремі комплексні складові: `Engine`, `Transmission`, `Wheel`, `Tire`;
- окремі будівельники: `EngineBuilder`, `TransmissionBuilder`, `WheelBuilder`, `TireBuilder`, `CarBuilder`;
- керуючий клас `Director`, який формує готові конфігурації автомобілів різних типів та класів;
- клієнтський клас `Main`.

Передбачено просту валідацію під час складання об'єктів:
- для двигуна перевіряються основні параметри;
- для коліс і шин перевіряються допустимі діапазони;
- для автомобіля перевіряється узгодженість діаметра диска та радіуса шини.
