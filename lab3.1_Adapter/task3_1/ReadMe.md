# USB charger
## У проєкті реалізовано

- `AdapterTypeCToMicroUsb` — адаптер **через композицію**.
- `AdapterTypeCToMicroUsbInheritance` — адаптер **через наслідування**.
- `Main` — демонстрація роботи обох варіантів.

## Відповідь на питання про двосторонній адаптер

Для цієї задачі **двосторонній адаптер створити можна**, якщо будувати його
**через композицію**. У такому випадку адаптер може виступати посередником між
`TypeCCharger` і `MicroUsbCharger`, виконуючи перетворення електричних
характеристик у потрібний формат.

Разом з тим, **через наслідування** повноцінний двосторонній адаптер у Java
робити недоцільно, оскільки клас не може одночасно наслідувати дві різні
реалізації зарядних пристроїв. Саме тому для цієї задачі більш гнучким і
рекомендованим є адаптер **через композицію**.
