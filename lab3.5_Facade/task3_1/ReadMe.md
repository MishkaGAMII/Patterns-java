## Опис
Реалізовано рефакторинг задачі з використанням шаблону проєктування **Фасад**.

Клієнтський код більше не працює напряму з такими класами, як:
- `CodecFactory`
- `BitrateReader`
- `AudioMixer`

## Структура
- `VideoConversionFacade` — фасад для конвертації відео.
- `Main` — спрощений клієнтський код.
- `VideoFile.play()` — безпечне програвання з автоматичним визначенням кодека.
- решта класів — підсистема бібліотеки відеоконвертації.
